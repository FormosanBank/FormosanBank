# 首頁

歡迎來到FormosanBank，這個以建置大規模資料庫為導向的計畫，此計畫專注於保存與復振臺灣的原住民族語言。臺灣原住民族語言在南島語系中具有相當特殊且重要的地位，但目前正處於瀕危的狀態，其中一些甚至有滅絕的風險，我們的使命是為這些語言創建一個全面、機器可讀取的語料庫，以促進語言學研究、語言教育及族語復振等工作。

在這裡，您可以找到17個語言語料庫的收集及處理說明，其中包括16個現存語言及休眠語言西拉雅語。目前公開語料庫包含8,219,206個詞及702.9小時的語音資料（詳細資訊請參見[此處](yu-liao-ku-jia-gou/yu-liao-ku/)），我們還提供語料結構及存取方式的介紹。您也可以從[GitHub](https://github.com/FormosanBank/FormosanBank)了解FormosanBank相關的工作及語料，而大多數語音檔案存放於[Hugging Face](https://huggingface.co/FormosanBank)。

在此感謝許多個人、學者、合作夥伴及機構單位的共同努力，FormosanBank資料庫才能在短時間內建置完成，並已具如此大規模！
