# 貢獻者

我們衷心感謝眾多支持 FormosanBank計畫的個人與團體，沒有大家的專業知識、奉獻和對保護臺灣南島語豐富語言遺產的堅定信念，此項舉措就不可能實現。

首先，我們由衷的感激臺灣的原住民族語言研究發展基金會（[ILRDF](https://www.ilrdf.org.tw/)，簡稱「原語會」）所提供的寶貴語料。原語會慷慨地分享其豐富的臺灣南島語語料，使我們的團隊得以推動「建立完整且機器可讀的語料庫」的工作，我們的研發進展歸功於原語會的大力合作與支持。
