# 電子報

歡迎來到FormosanBank電子報頁面！在這裡，我們透過電子報記錄在復振和保存臺灣南島語的過程。這些報導內容是您了解我們的最好窗口，報導內容包含最新發現、專案里程碑，以及分享創新方法。

每期電子報將深入介紹我們的工作，從語料庫最新的擴展，以及正在開發的支援語言研究和族語復振工作的新功能、工具和資源。透過點選子頁面，能閱覽各期電子報，從中將發現更詳盡的文章、進度報告以及對FormosanBank日益成熟的見解。
