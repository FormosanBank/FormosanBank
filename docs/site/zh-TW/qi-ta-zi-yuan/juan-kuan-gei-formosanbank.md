# 捐款給FormosanBank

### 您必須做什麼？

您必須同意您的資料以 CC-BY-NC ([英文](https://creativecommons.org/licenses/by-nc/4.0/deed.en)；[中文](https://creativecommons.org/licenses/by-nc/4.0/deed.zh-hant)) 的開放原始碼授權條款發表。如果您偏好不同的開放源碼授權，請與我們討論

***

### 人們可以如何使用您的資料？ <a href="#what-can-people-do-with-your-data" id="what-can-people-do-with-your-data"></a>

任何人都可以為任何目的使用 FormosanBank 的資料，但有以下限制：

* 任何人不得出售您的資料。
* 任何人不得出售使用您的資料所訓練的人工智慧。
* 任何使用您資料的人都必須承認您的工作。

只要遵守這些規則，任何人都可以將您的資料用於科學研究、文化產品、創造人工智慧或任何其他目的。

有些作者希望允許商業用途。如果您希望允許商業用途，請與我們討論。

***

### 您保留哪些權利？ <a href="#what-rights-do-you-keep" id="what-rights-do-you-keep"></a>

* 您仍然是您資料的作者和擁有者。
* FormosanBank 會承認您是您資料的作者和擁有者。
* 任何使用您資料的人必須承認您是資料的作者和擁有者。
* 您仍然是唯一可以出售您的資料的人。

***

### 流程是什麼？如何運作？ <a href="#what-is-the-process-how-does-this-work" id="what-is-the-process-how-does-this-work"></a>

1. 我們會與您討論您的資料，以及您的任何限制。這些限制可能包括
   * 我們可以協助匿名化部分資料。
   * 我們可以等到特定日期之後才公佈資料。
   * 我們可以協助尋找和修正資料中的錯誤。
2. 您可以決定您的工作如何得到認可。用戶應該連結到您的網站嗎？他們應該引用你的論文嗎？
3. 您將資料寄給我們。
4. 我們將資料轉換成 FormosanBank 格式。
5. 我們仔細檢查資料，確保沒有錯誤。如果您願意，您也可以檢閱資料。
6. 我們發佈資料作為FormosanBank的一部分。
