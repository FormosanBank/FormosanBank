# 語料庫

歡迎來到FormosanBank語料庫區！在這裡，您可以找到FormosanBank所使用的語料庫的詳細文檔。這裡集結的每個語料庫皆代表一個獨特的語料集，包含著各類文本和錄音。我們的語料庫旨在於支持語言學研究、語言教育和族語復振工作，使研究人員、教育工作者和族人皆能夠輕鬆存取與分析這些瀕危語言。以下是目前FormosanBank所包含的語料庫列表：

* [族語Ｅ樂園](zu-yuele-yuan.md)
* [原語會族語線上辭典](yuan-yu-hui-zu-yu-xian-shang-ci-dian.md)
* [維基百科](wei-ji-bai-ke.md)
* [總統道歉](https://docs.google.com/document/d/1eXZzq4oKyJD2CIsgI6vB6sZi9e0CoYoO/edit#heading=h.1hmsyys)[文](zong-tong-dao-qian-wen.md)
* [國立臺灣大學排灣語自動語音辨識](guo-li-tai-wan-da-xue-pai-wan-yu-zi-dong-yu-yin-bian-shi.md)
* [Virginia Fey阿美語辭典](virginia-feyamei-yu-ci-dian.md)
* [排灣故事](pai-wan-gu-shi.md)

### 僅提供英文頁面的語料庫

英文版GitBook為主要版本，目前已收錄全部22個公開語料庫的頁面。上述翻譯頁面仍不完整，完整且最新的清單請見[英文版語料庫索引](https://ai4commsci.gitbook.io/formosanbank/the-bank-architecture/corpora)。缺少翻譯頁面並不表示該語料庫仍在處理中。

***

### 目前數據

目前公開語料庫共包含**8,219,206個詞**及**702.9小時的錄音**，涵蓋16個現存語言及休眠語言西拉雅語，共17個語言。依語言、方言及語料庫分類的精確表格由程式自動產生，請見[英文版語料庫頁面](https://ai4commsci.gitbook.io/formosanbank/the-bank-architecture/corpora)。
