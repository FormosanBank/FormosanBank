How to read this

  • One row = one corpus × dialect label. There are 57, covering {{TOT_FILES}} published XML files. Only files directly under each corpus’s XML/ are counted. Frozen copies under CodeAndDocs/ are left out. Files whose dialect is unknown are out of scope, which removes all of Wikipedias.
  • The comparison: our label is mapped to the list’s dialect through the Chinese names in dialects.csv (e.g. Coastal = 海岸, Southern = 南勢, Sekolik = 賽考利). For trv, Truku = 太魯閣語 and Tegudaya = 德固達雅語. Then I check whether the place the source names appears under that dialect in the list, at the most specific level the source gives: village or community, township, or county only.
  • “Linked to the list by” says what the match rests on. source’s own words: the source names the place in a form the list uses. my reading of a romanized name: e.g. “Changpin” = 長濱. my outside knowledge of a place: e.g. Paiwan “Kuɫaɫau” = 古樓. These identifications are mine, not the source’s. our own summary of a source I couldn’t see: e.g. Fey’s introduction is online only.
  • What counts as a location: a statement tied to the data or its speakers, such as “the data was collected from…”, a consultant’s village, or a speaker saying where they are from. A sentence that only says where the language is spoken (“Thao is spoken at Sun-Moon Lake”) does not count. Those cases are in the not-found table, with a note that the statement agrees with the list.
  • What the list measures: where each dialect is spoken today (ROC year 110 = 2021). The sources date from 1954 to the 2020s. A speaker’s home village is not always where the recording was made. Several NTU speakers say they are speaking “here in Taipei”.

Other things I noticed

  • WakelinTexts README says “collected on Orchid Island” (lines 17 and 21), but the 1958 article never says where the texts were collected. A search of its full text layer (22 pages) finds 0 hits for Orchid, Island, Botel, Tobago, Lanyu, Kotosho, Taiwan or Formosa. It gives only “Informant: <name>, <date>”. In two texts the narrator describes travelling by boat and bus to “Taytu” and “to get here”. The agent reads that as the recording being made off the island, but that is an inference.
  • Poinsot dictionary: “southern speech” filed under the northern dialect. The book’s key has N：北方話 and S：南方話. Our build files both as Southern, which is 南勢. The list calls 南勢 “南勢阿美語(原北部阿美語)”, the former Northern dialect. That fits 北方話 but not obviously 南方話 (1,169 sentences). The book gives no places for either.
  • Hundred Paiwan Stories texts 095 and 098 were set to Central in commit 90094b232 (2026-03-15), and the commit gives no reason. The book heads 095 “Makazayazaya dialect”. If that is 瑪家, the list puts it in Northern Paiwan.
  • ILRDF Seediq: the ILRDF data itself tags 76 Seediq entries as 德鹿谷 (75) or 都達 (1), while the whole file is labelled Tegudaya. This is from the agent’s report; I did not re-check it.
  • NTU place metadata never reaches the published XML. NTU’s JSON meta.language field carries places: 台東縣長光社區 (Amis), Xinshe (新社) (Kavalan), TapangU and Tfya (Tsou), Tong-he(東河) (Saisiyat), Mayrinax (汶水) (Atayal). None of it is in XML/.
  • Secondary data inside “fieldwork” corpora. Chang’s Seediq grammar takes some chapter 3–4 examples from 谷口龍子 (1994) and 張仲良 (1994). The Nowbucyang thesis takes some forms from teaching materials. Neither marks which sentences these are.
  • About the list itself. Seediq 都達語 is listed for exactly the same nine 宜蘭縣 大同鄉 villages as 四季泰雅語. I can’t tell from the PDF whether that is intended. One village cell reads “美和村、金崙鄉”: a township name sits in the village column (海岸阿美語, 太麻里鄉), which looks like a slip. 桃園縣 appears under its pre-2014 name.

How this was done

  • The list: the 12-page PDF’s tables were read with pdfplumber. Blank cells take the value from the row above, including across page breaks. That gives {{LIST_N}} rows and 42 dialects, which matches the PDF’s own title. The full table is at the bottom of this page.
  • Scope: every <TEXT> on main (2a345f0d9) with a dialect other than unknown, excluding ePark and Presidential_Apologies. That is 29 corpora and 57 labels. All reading was done from a separate worktree at main.
  • Sources read: each README; source PDFs, docx and metadata in CodeAndDocs/ and in the Formosan-<Name> dev repos. Six read-only research agents found and quoted the passages. I re-checked the key ones myself against the sources: the RauDong village tally, the Wakelin full-text search, NTU’s meta.language values, the Hundred Paiwan Stories headings, the Pa-Verbs footnote, the Nowbucyang abstract and consultant table, Tang’s Paradisec location, and the Wilang Yutas captions. The Poinsot preface and key were fetched for this check from the public GitHub scan repository miaoski/amis-chinese-poinsot (page 3).
  • Not reachable from here: the ILRDF and Glosbe websites, YouTube descriptions, Paradisec catalogue pages, the SIL archive (Huteson) and new-amis.moedict.tw (Fey). Anything that exists only there is reported as not found.
  • Changed: nothing in any corpus or README.
