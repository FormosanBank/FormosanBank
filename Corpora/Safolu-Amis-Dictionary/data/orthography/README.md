# Safolu orthography data

`Amis_Safolu_113.tsv` is the historical candidate table used for the retained
XML. It is preserved as evidence, not loaded by the revised build. Current main
does not contain a shared Safolu profile/table, and current conversion checking
flags `u → o` plus incomplete `d`/`o` routing. Resolve these through a separate
shared review before rebuilding or clearing the corpus (POL-049).
