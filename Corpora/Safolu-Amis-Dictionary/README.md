## Data and source coverage

The pinned source contains 49,419 example fields. The source audit accounts for
all of them:

- 49,179 records remain in canonical XML;
- 261 duplicate source rows are retained in the generated duplicate ledger;
- 22 unrecoverable fields are retained in the generated rejection ledger;
- 61 ordinal-keyed, fail-closed overrides repair confirmed source
  digitization or alignment problems;
- 140 additional Chinese readings are preserved as `ver="alt"` under POL-025.

Each sentence contains source-faithful original FORM, Safolu original PHON,
Ortho113 standard FORM, and Ortho113 standard PHON. A Chinese TRANSL is present
when supplied by the source. The source does not contain aligned word or
morpheme analysis, so the corpus does not invent W or M tiers under POL-036.

The original spelling distinguishes `o` and `u` and uses both legacy `g` and
current `ng` for /ŋ/. Original FORM therefore remains a source anchor under
POL-001. Standard FORM is derived with the reviewed Coastal mapping in
`Orthographies/ConversionTables/Amis_Safolu_113.tsv`, using the current
single-pass standardizer under POL-002. PHON tiers are regenerated by
`add_phonology.py` under POL-003. See
`CodeAndDocs/docs/orthography_evidence.md` and
`CodeAndDocs/docs/dialect_evidence.md` for the evidence.

## Reproduction

Use a current FormosanBank checkout containing the Safolu orthography profile,
conversion table, and `standardize.py --single-pass`. The default command
builds in a temporary directory, regenerates the source ledgers, runs current
cleaning and tier derivation, validates the result, and requires a byte-for-byte
match with the committed XML:

```sh
Corpora/Safolu-Amis-Dictionary/CodeAndDocs/make_xml.sh --check
```

To reuse already fetched pinned sources and retain all reports:

```sh
SOURCES_DIR=/path/to/pinned/_sources \
REPORT_DIR=/new/absolute/report/path \
Corpora/Safolu-Amis-Dictionary/CodeAndDocs/make_xml.sh --check
```

`--apply` replaces the one canonical XML file only after the same checks pass.
Refresh its statistics afterward with:

```sh
python QC/utilities/get_corpus_stats.py \
  Corpora/Safolu-Amis-Dictionary --strict
```

Downloaded sources, generated ledgers, reports, warning CSVs, and caches are
not committed. The canonical output directory is `XML/`; the pipeline does not
use the legacy `Final_XML/` directory or a POL-035 snapshot.
