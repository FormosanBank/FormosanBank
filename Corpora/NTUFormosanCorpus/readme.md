# NTU Corpus of Formosan Languages

This corpus publishes the Grammar, Sentences, and Stories portions of the
[NTU Corpus of Formosan Languages](https://corpus.linguistics.ntu.edu.tw/)
in FormosanBank XML.

## Contents

The current release contains:

- 193 XML files
- 20,255 sentence elements
- 14,655 sentence-level audio references
- Grammar data for Kanakanavu, Sakizaya, and Seediq
- Sentence collections for Bunun, Kanakanavu, and Rukai
- Stories in Amis, Atayal, Bunun, Kanakanavu, Kavalan, Rukai, Saisiyat,
  Sakizaya, Seediq, and Tsou

The NTU Paiwan material is published separately as `NTU_Paiwan_ASR`.

## Source and publication authority

`CodeAndDocs/grammar`, `CodeAndDocs/sentence`, and `CodeAndDocs/story`
contain the 378 public NTU JSON inputs used by the current build. The pinned
`CodeAndDocs/source_snapshot.json` records their paths, record counts, and
SHA-256 digests. It was checked against the official NTU data store on
2026-08-22: 321 paths were available from the live store and 57 unavailable
paths retain the previously archived public bytes.

The published XML is the reviewed output of private development commit
`8a13dce0ac311e97ed79dae44186517de3a826c8`. The public source snapshot,
repair registry, and legacy-only build scripts were copied from that same
build so the public XML can be regenerated without the private Paiwan inputs.

## Reproduction

Use a current FormosanBank checkout and its Python environment. From this
corpus directory:

```bash
export FORMOSANBANK_ROOT=/path/to/FormosanBank
export PYTHON="$FORMOSANBANK_ROOT/.venv/bin/python3"
./CodeAndDocs/make.sh
```

The build:

1. verifies every pinned JSON source;
2. parses the three source collections into a clean staging directory;
3. applies the recorded source-field and morpheme-structure repairs;
4. runs FormosanBank cleaning, standardization, and Ortho113 phonology;
5. expands reviewed source alternatives and preserves uncertainty;
6. marks source-owned word and morpheme glosses as original;
7. audits source coverage and runs the current text validator.

XML generation does not require audio. `--with-audio` is available for a
source-audio audit, but the repository-level download contract is the
preferred way to obtain published audio.

## Audio

Run the following command from this directory:

```bash
./download_audio_data.sh
```

The repository-level `audio_sources.json` pins the public Grammar and Stories
datasets on Hugging Face. The current contract contains 3,754 unique Grammar
files and 10,845 unique Story clips. Three source Grammar clips are not usable,
and eight more are absent from the pinned public Grammar dataset. All eleven
are omitted reproducibly by `scripts/parse_grammar.py`. Two hosted Story
clips no longer referenced by the reviewed XML are declared explicitly in
`audio_extras.json`.

Audio is not committed to Git. The statistics refresh downloads one corpus,
recomputes its duration rows, and removes the temporary audio afterward.

## Source-faithful repair policy

The source includes incomplete alignments, annotation codes, optional forms,
and gloss rows whose form and analysis segmentation disagree. The processing
pipeline does not invent missing linguistic content. It uses reviewed source
rows to repair recoverable structure, preserves uncertain content with
`UNCLEAR`, and withdraws unsupported morpheme analyses while retaining their
source word as the anchor.

Source word and morpheme glosses use `kindOf="original"`. Standard forms and
phonology are generated by the shared FormosanBank pipeline. Source notes are
preserved in `notes` where their attachment can be established.

## Current validation status

The 2026-08-22 build completed with:

- 57 repository tests passing in the development repository
- 1,025 FormosanBank tests passing in the publication checkout
- 378 pinned JSON files and 41,508 source records verified
- 193 canonical XML files and 20,255 canonical sentences covered
- no hard text, gloss, duplicate, or port-readiness findings
- online audio parity passing and fresh audio-duration statistics

Soft text, gloss, and duplicate findings remain where the public source itself
contains unusual characters, incomplete segmentation, repeated utterances, or
source-attested alignment differences. These are review signals rather than
unrecorded publication edits.
