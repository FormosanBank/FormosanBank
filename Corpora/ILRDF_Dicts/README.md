## Scope

This corpus contains example sentences and linked recordings from the Indigenous Languages Research and Development Foundation online dictionaries for 16 Formosan languages.

The canonical `XML/` directory contains 16 language files, 167,821 sentence elements, and 132,402 AUDIO references. Each file uses `dialect="unknown"` because the aggregate API source does not identify a sentence-level variety.

## Reproducibility

`CodeAndDocs/source_data/snapshots/` contains one deterministic gzip JSON snapshot per language. These 16 official API snapshots are the reproducibility boundary. `source_manifest.json` records compressed and uncompressed hashes, snapshot dates, query counts, and source URLs.

The build:

- verifies every committed snapshot against its manifest hashes
- keeps source spelling and source translations
- combines repeated sentence records without losing distinct translations or audio
- excludes only documented unusable or ambiguous recordings
- generates deterministic sentence IDs from the source form
- applies the pinned FormosanBank standardizer, cleaner, and phonology tools
- restores source-owned FORM, TRANSL, and AUDIO tiers after shared processing
- audits all 167,821 sentences for source drift

To reproduce the XML with the pinned FormosanBank authority commit:

```bash
export FORMOSANBANK_AUTHORITY=/path/to/FormosanBank-at-3a3c47c
export FORMOSANBANK_PYTHON=/path/to/python3
Corpora/ILRDF_Dicts/CodeAndDocs/reproduce.sh
```

The script does not contact the live dictionary or download audio. Source refresh is a separate, explicit network operation implemented by `CodeAndDocs/refresh_source.py`.

## Source-Specific Decisions

- API records with positive frequency or a nonempty source field are treated as published, matching the live dictionary display.
- Empty and punctuation-only source records are excluded.
- Three documented Kanakanavu lesson numbers stored in the target field are excluded as translations while their source sentences and audio remain.
- Internal `?` corruption in Kanakanavu, Saaroa, and Tsou is repaired only when replacing it with `ʉ` or `ɨ` produces a word attested elsewhere in the same snapshot.
- Original FORM and TRANSL tiers remain source-owned. Standard FORM and PHON are generated by FormosanBank tooling.
- FORM formatting normalizes layout spaces, Unicode composition, quote glyphs, and invisible zero-width characters without rewriting lexical content.
- `CodeAndDocs/source_data/audio_exclusions.json` records evidence for every suppressed recording ID.
- A fail-closed check rejects any recording URL assigned to more than one sentence form. Forty cross-language collisions are documented and suppressed because neither assignment can be trusted.

## Audio

Audio is not committed to Git. Run `download_audio_data.sh` from the corpus directory to retrieve the FormosanBank-hosted audio collections. The XML retains the official ILRDF source URL and deterministic local filename for each included recording.
