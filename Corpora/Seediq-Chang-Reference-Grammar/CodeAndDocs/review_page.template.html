How to review

Each card is one example from Chang Yung-li (2000), 賽德克語參考語法. The first row is the Seediq, the second row is the gloss printed under each word, and below them is the free translation. Open the book at the page shown on the card and make each card match the book exactly.

  • Misread characters. Fix any Chinese character, Seediq letter or punctuation mark that differs from the book. Type the book's spelling, even where it looks unusual.
  • Misaligned glosses. Each gloss must sit under the word it belongs to. Click a box, then use the buttons under the table: Insert box and Delete box shift only that row; Insert column and Delete column change both rows.
  • One word per box. If a word or gloss is missing, insert a box. If the book prints no gloss under a word, write ∅. When one gloss spans two words (for example 跟 over daha ka), put it under the first word and ∅ under the second.
  • Morphemes. A hyphenated word should have a gloss with the same number of parts: s-usa-un-mu over S-去-PF-我. Infixes are written inside the gloss as the book prints them.
  • Keep the book's notation. (ka) marks optional material, laqi/heya marks alternatives, and {…} groups alternatives across words. In a translation, = separates alternative translations. Keep all of these as they are.
  • Proper names such as pawan and walis are glossed as themselves.
  • Notes. If you are unsure, or something cannot be fixed in the boxes, write it in the note. Notes go to the maintainer.
  • Mark reviewed when a card matches the book, even if you changed nothing. That is how we know it was checked.

Cards with a yellow tag were flagged by an automatic check as likely problems. The tag is only a hint about where to start.
