# Chinese Union Version reference

The checked-in USFM files contain the Chinese Union Version in traditional script with new punctuation. The source package identifies the work as public domain.

- Source: https://ebible.org/cmn-cu89t
- Language: Mandarin Chinese, traditional script
- Source text date recorded by the package: 2024-12-30
- Source files date recorded by the package: 2025-12-12

The `.gz` files use deterministic compression. Decompression restores the exact source bytes whose SHA-256 identities are recorded in `../../data/reference_translation_manifest.json`.
