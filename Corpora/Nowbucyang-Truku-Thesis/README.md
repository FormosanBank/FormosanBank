# Nowbucyang Truku Thesis

This corpus contains linguistic examples from Lowking Wei-Cheng Hsu / 許韋晟's 2008 MA thesis, *太魯閣語構詞法研究 [Word Formation in Truku]*, National Hsin-Chu University of Education.

The published XML contains 276 Truku sentences (`xml:lang="trv"`, `dialect="Truku"`), 1,131 word elements, and 1,311 morpheme elements. Chinese translations and W/M analysis are retained only where the source and reviewed alignment support them.

## Orthography

The source uses Truku Ortho94. Original FORM tiers preserve the reviewed source spelling and segmentation. Standard FORM and PHON tiers are generated by the shared FormosanBank pipeline with the Truku column of `Seediq_94_113.tsv` and the Ortho94 phonology profile.

## Reproduction

Run the single public entry point from the FormosanBank checkout:

```bash
Corpora/Nowbucyang-Truku-Thesis/CodeAndDocs/make_xml.sh
```

The script restores a reviewed source-tier snapshot, then runs `clean_xml.py`, `standardize.py`, and `add_phonology.py` in the canonical order. It reproduces the committed XML byte for byte.

The public reproducibility package intentionally excludes the protected thesis PDFs, decrypted copies, page images, extracted page text, and private permission correspondence. Full source extraction and source-alignment evidence remain in the private development repository. The public snapshot contains only the publication input needed to regenerate the corpus XML.

## Stable identifiers

This update preserves the existing public TEXT ID and every surviving public S/W identifier. It also preserves every surviving M identifier and never reuses a public identifier for different lexical content.

- Repeated source labels are resolved by [stable_sentence_ids.csv](CodeAndDocs/stable_sentence_ids.csv).
- Three published duplicate sentences are represented by equivalent retained sentences documented in [duplicate_sentence_decisions.csv](CodeAndDocs/duplicate_sentence_decisions.csv).
- The new page 95 sentence uses `HSU_LOWKING_TRUKU_WORDFORMATION_2008_C03_E036B_P0095_01`; the existing page 116 `Q-qtul` sentence keeps public ID `HSU_LOWKING_TRUKU_WORDFORMATION_2008_C03_E036B`.
- Legacy M elements that had no gloss are retired instead of being preserved as unsupported morpheme analyses.

The complete update comparison is in [published_id_stability.csv](CodeAndDocs/published_id_stability.csv).
