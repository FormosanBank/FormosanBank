# Source and build notes

The build uses the reviewed `raw_data/reviewed_examples.tsv`, `reviewed_variants.tsv` and `reviewed_morpheme_alignments.tsv`. The first preserves all 39 numbered source units, exclusions and the rejected interpretation; variants implement the two explicit optional spans. The morpheme table handles eleven flat-infix gloss pairs while preserving their source W glosses and adding standard notation separately. The committed article extracts and direct-check ledger retain independent page evidence. `build_xml.py` regenerates XML and source/coverage ledgers; `check_source_alignment.py` is read-only. The source map records source fields only; generated standard forms remain in XML.

The source is the 2014 ANU volume, PDF SHA-256 `fab9b60ce52e47530805204c1d5beed02e52e63972e8315d9a1996c8e79248f1`; this chapter occupies PDF pages 74–84. Its first-page CC BY 4.0 grant applies to the retained extracts. All eleven pages, numbered examples, shared translations, page continuations, beginning/end and references were reviewed. Inline discussion restates those examples and schemas; it does not add another acquired numbered-example population. The two separate examples printed as (27) retain separate IDs.

Madeline Boese's full-document review on 2026-08-10 approved the restored W/M analysis and removal of the impossible starred translation of example 13. Earlier feedback specifically required the missing analysis, apostrophe-to-glottal-stop PHON conversion and punctuation-free PHON. Preserve source PTC/PRT, AC.escape/AV.escape, tiwaŋ/Ciwang and Jisus/Jesus differences, both 17a readings, and the seven exact bracket values guarded by `restore_source_notation.py`.

Current POL-023 supersedes the later file-wide mirror addition: examples 3 and both variants of 6 have no internal source segmentation and carry W without M. This removes fourteen mirror M copies and their duplicated tiers; every source W/gloss survives. All other sentences retain complete M coverage. The old notes claiming five bracketed records still lacked W/M were stale and are corrected.

The source profile supplies the same Truku phonemes to conversion validation and original PHON generation. Tsukida's [2012 workshop paper](https://lingdy.aa-ken.jp/wp-content/uploads/2012/01/120217_naomi_tsukida_h.pdf), p. 2 footnote 1, and [2009 dissertation abstract](https://gakui.dl.itc.u-tokyo.ac.jp/cgi-bin/gazo.cgi?no=217214), phonology summary, support g /ɣ/, l /ɮ/ and e /ə/. The chapter prints ŋ; the standard writes ng. The old Ortho94 generation call disagreed with the validated profile at g and l. Source refresh never runs as part of generation.

The eleven G001 HARD findings are the exact source W/gloss pairs accepted in the full-document review, not newly inferred segmentations. Their IDs and count are pinned in the source tests; the source glosses remain unchanged. G003 reports their retained gap-hyphen roots because the source W writes flat hyphens rather than angle brackets. Six V122 signals are ordinary source translation punctuation. PDF-text heuristics remain review signals; no script labels arbitrary new findings accepted or emits an automatic ready-to-port verdict.

The legacy orthography extractor places trv/Truku data under Seediq/Truku. `validate.sh` copies the current Truku/Truku reference byte-for-byte into that expected report-only layout and verifies the copy, so both orthography and vocabulary comparisons actually run. No shared reference or XML language metadata is altered. Existing inputs remain under this directory; disposable validation logs belong outside the corpus.
